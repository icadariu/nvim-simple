# Security Policy

## Supported Versions

Only the latest version of this configuration is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do not report it through public issues. Instead, please use the GitHub "Report a vulnerability" feature or follow standard private disclosure practices.

I take all security reports seriously and will aim to respond within 48 hours.

## Best Practices for this Config

- **Secrets**: Never commit tokens, passwords, or SSH keys to this repository.
- **Plugins**: Be careful when adding new plugins. Only use plugins from trusted sources.
- **Signed Commits**: This repository requires signed commits for the `main` branch to ensure code integrity.
